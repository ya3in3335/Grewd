# خدمات DZ 🇩🇿

أدوات مجانية وبسيطة للجزائريين — تعمل كلياً في المتصفح، و **GitHub هو الباك اند**.

| الأداة | الوصف |
|---|---|
| 🏦 CCP ⇄ RIP | حساب رقم RIP ومفتاح CCP لبريد الجزائر |
| 🎓 معدل البكالوريا | كل الشعب، معاملات قابلة للتعديل، حفظ تلقائي للعلامات |
| 💼 الراتب الصافي و IRG | CNAS 9% + جدول IRG لقانون المالية 2022 |
| 💶 تحويل العملات | السعر الرسمي وسعر السكوار |
| ✦ برو | تحويل RIP بالجملة + تصدير CSV/PDF، كشف راتب قابل للطباعة، سجل الحسابات |
| 💬 الاقتراحات | تُخزَّن كـ GitHub Issues وتُعرض مباشرة في الموقع |

## كيف يعمل GitHub كباك اند

- **الاستضافة:** GitHub Pages (ملف `.github/workflows/pages.yml` ينشر الموقع عند كل push).
- **البيانات (CMS):** ملفات `data/*.json` — عدّل `data/rates.json` من واجهة GitHub لتحديث أسعار العملات، أو `data/irg.json` و `data/bac.json` عند تغيّر القوانين. لا حاجة لإعادة كتابة الكود.
- **قاعدة بيانات الاقتراحات:** GitHub Issues بالوسم `اقتراح`، تُقرأ عبر GitHub REST API.

## التشغيل محلياً

```bash
python3 -m http.server 8000
```

ثم افتح http://localhost:8000

> النتائج للاسترشاد فقط. تأكد دائماً من RIP في وثائق بريد الجزائر الرسمية قبل أي تحويل.
