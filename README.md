## كيف يعمل GitHub كباك اند

- **الاستضافة:** GitHub Pages من فرع `gh-pages`. أي تعديل على `main` يُنسخ تلقائياً عبر `.github/workflows/pages.yml`.
- **البيانات (CMS):** `data/bac.json` (المعاملات)، `data/irg.json` (جدول الضريبة)، `data/wilayas.json` (الولايات والإحداثيات). عدّلها من واجهة GitHub بدون لمس الكود.
- **الاقتراحات:** GitHub Issues بالوسم `اقتراح`.
- **الخصوصية:** لا يوجد سيرفر. السجل والعلامات وسعر السكوار تُحفظ في جهاز المستخدم فقط.
